# Changelog

Todos los cambios notables a este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Chngelog](https://keepachangelog.com/en/1.0.0/), mantenemos las versiones de acuerdo a [Semantic versioning](https://semver.org/spec/v2.0.0.html).

**Dada una versión número MAJOR.MINOR.PATCH** (aplica a partir de 2.0.0)

* Se incrementará **MAJOR**, cuando se implemente un nuevo tipo de **Módulo** que genere incompatibilidad con versión anterior.
* Se incrementa **MINOR**, cuando se agregue una o más **nueva(s) funcionalidad(es) a la aplicación**.
* Se incrementa **PATCH**, cuando se implemente un **fix**.

### Tipos de cambios
* **Feat** para funcionalidades nuevas.
* **Fixed** para corrección de errores.
* **Chored** para cambios menores que no afectan la funcionalidad.
* **Docs** para cambios en la documentación.
* **Style** para cambios de formato (sin afectar la funcionalidad).
* **Refactor** refactorización del código sin alterar su comportamiento.
* **Perf** para mejoras de rendimiento.
* **Test** adición o modificación de pruebas.
* **Build** para cambios relacionados con herramientas de construcción o dependencias externas.
* **CI** para cambios en el flujo de integración continua.
* **hot fix** Cambio crítico, urgente, no pasará por QA.
